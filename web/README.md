# Health4AI website

Static Astro marketing website. This directory does not read personal health records.

## Local verification

Run `npm ci`, `npm run build`, and `node --test scripts/performance.test.mjs`.
The tests inspect emitted HTML and image files, including brand image sizing,
immediate hero rendering, reduced motion, and that the App Store download CTA
is present with no leftover waitlist/TestFlight copy.
Use `npm run preview -- --host 127.0.0.1` to inspect the production build.

Brand logo derivatives are generated by Astro from `public/logo.png`; do not
commit generated WebP files or `dist/`. Homepage sections are split into
`HomeHero.astro` and `HomeDetails.astro`; their shared styles remain on the homepage.
Production publication requires separate approval.
